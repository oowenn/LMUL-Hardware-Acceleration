Making neural networks 3x smaller with approximate multiplication

L-Mul replaces expensive floating-point multiplication with simple addition in log-space. Less silicon, less power, nearly identical accuracy.

How it works

Multiplication → Addition

Instead of multiplying mantissas (O(n²)), L-Mul adds exponent+mantissa fields directly (O(n)). The logarithmic representation makes this work.

def lmul_bits(a, b):
    a_bits = a.view(torch.int32)
    b_bits = b.view(torch.int32)
    
    a_bf16 = (a_bits >> 16) & 0xFFFF
    b_bf16 = (b_bits >> 16) & 0xFFFF
    
    a_sign = (a_bf16 >> 15) & 0x1
    b_sign = (b_bf16 >> 15) & 0x1
    a_field = a_bf16 & 0x7FFF
    b_field = b_bf16 & 0x7FFF
    
    sum_full = a_field + b_field + 0x4080
    carry = (sum_full >> 15) & 0x3
    
    field_sel = torch.where(carry == 1, sum_full & 0x7FFF, 0)
    field_sel = torch.where(carry >= 2, 0x7FFF, field_sel)
    
    s_result = a_sign ^ b_sign
    result_bits = (s_result << 15) | field_sel
    result = (result_bits << 16).view(torch.float32)
    
    return result + (result / 32) + (result / 64)
Results

Accuracy across architectures

Tested on MLP, CNN, LSTM, and Transformer models. Neural networks tolerate the approximation surprisingly well.
